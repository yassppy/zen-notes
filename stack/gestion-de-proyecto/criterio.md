# criterio

## ¿Qué es criterio?
Es la capacidad de identificar qué debo evaluar en una situación para poder tomar mejores decisiones.

## Ejemplo

La consulta en mi base de datos es lenta.

En lugar de tomar una decisión inmediatamente, evalúo diferentes opciones:

Crear índices.
Particionar las tablas.
Optimizar la consulta.
Revisar la estructura de la base de datos.
Aumentar los recursos.

Después evalúo lo bueno y lo malo de cada alternativa, considerando factores como rendimiento, complejidad, costo y mantenimiento.

Finalmente, con esa información, tomo una decisión informada.

## Fórmula

Situación → Qué debo evaluar → Opciones → Pros y contras → Decisión
