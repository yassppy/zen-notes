# apk_depurar_android
## Activar el modo desarrollador
- Ve a Ajustes (Settings) de tu Android
- Entra a Acerca del teléfono (About phone)
- Identificadores del dispositivo (Device identifiers)
- Hay uno que se llama número de compilación (build number) le debes dar clic 7 veces te va a pedir tu contraseña del celular, bueno tu pin.
- Una ingresado te va a salir que eres desarrollador.

## Activar la depuración por USB
- Vuelve a Ajustes
- Ve a Sistema (System)
- Ahora debería aparecer `Opciones de desarrollador` (`{ } Developer Options`)
- Entra ahí y activa Depuración por USB (USB debugging)

### OPCIONAL EN GOOGLE AI STUDIO
- En la web te va a permitir seleccionar el dispositivo correcto.
- Te muestra un mensaje de depuración por USB en el celular y le das a permitir.

### OPCIONAL PARA FLUTTER: 
- Una vez que conectes el USB te va a parecer una notificación, pantalla Allow USB debiggong? le das a Permitir siempre Allow
- En las notificaciones seleccionas el que dice USB file transfer turned les da clic y le das a Activar File Transfer
