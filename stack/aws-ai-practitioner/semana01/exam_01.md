# exam_01

P1: ¿Cuál de las siguientes opciones describe mejor el uso de redes neuronales para esta tarea?
- Las redes neuronales son un tipo de modelo de aprendizaje profundo inspirado en la estructura y función del cerebro humano. Consisten en nodos interconectados que pueden aprender a reconocer patrones en los datos, como imágenes de dígitos escritos a mano.

P2: Una empresa está desarrollando un sistema de inteligencia artificial (IA) para controlar un automóvil autónomo. El sistema aprende por medio de interacciones de prueba y error con el entorno de conducción y recibe recompensas por acciones seguras y eficientes. ¿Qué enfoque de machine learning (ML) se utiliza en esta situación?
- Aprendizaje por refuerzo

P3: Una empresa está desarrollando un modelo de lenguaje de gran tamaño (LLM) para tareas de procesamiento de lenguaje natural, como la generación de texto, el resumen y las respuestas a preguntas. ¿Cuál de las siguientes opciones describe mejor el rol de las incrustaciones en el contexto de los LLM?
- Las integraciones son representaciones numéricas de palabras o símbolos, donde las palabras semánticamente similares tienen representaciones vectoriales similares.

P4: Una empresa ha entrenado previamente a un modelo de lenguaje grande en un vasto conjunto de datos de texto. La empresa desea adaptar este modelo previamente entrenado para que realice tareas específicas, como el análisis de sentimientos y el resumen de documentos.
¿Cuál de las siguientes opciones describe mejor el proceso de ajuste?
- El ajuste es el proceso de adaptar un modelo de lenguaje previamente entrenado para realizar tareas específicas mediante un entrenamiento adicional con datos etiquetados para esas tareas.

P5: Un equipo tiene la tarea de elegir un modelo de inteligencia artificial (IA) generativa que pueda reconocer e interpretar distintas formas de datos de entrada, como texto, imágenes y audio.
¿Cuál de las siguientes arquitecturas de modelo es la más adecuada para esta tarea?
- Los modelos multimodales están diseñados específicamente para gestionar entradas de múltiples modalidades, como texto, imágenes, audio y video. Estos modelos pueden fusionar y procesar información de diferentes fuentes de entrada.
