# curso_gentle_shell
Es el que recomienda el creador
## Instalación
- Desde el power Shell vas a instalar pnpm con el siguiente comando
```powershell
iwr https://get.pnpm.io/install.ps1 -useb | iex
# Una vez instalado, cerra el power shell y volverlo a abrir
pnpm --version
```
- Ingresar a la siguiente página https://github.com/Gentleman-Programming/gentle-shell
- Clonar el repositorio
```sh
git clone https://github.com/Gentleman-Programming/gentle-shell.git
```
- Dirigirte a la carpeta ``gentle-shell`` e instalar las depencencias
```sh
pnpm install
```
- Crear el link
```sh
npm link
```
- Una vez creado el link podras ir desde cualquier proyecto y ingresar desde Warp
```sh
gentle-shell
```
